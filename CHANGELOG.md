### Added

- Default Dachen (大千) 4×10 keyboard layout as base configuration
- Hsu (嘸蝦米) and Eten (倚天) 26-key optional layouts
- One-tap OpenCC (Open Chinese Convert) simplified–traditional conversion in candidate bar
- libchewing 0.13.x integration for Chewing (酷音) IME support
- GitHub Actions CI workflow skeleton for debug and release builds
- Issue and PR templates for community contributions
