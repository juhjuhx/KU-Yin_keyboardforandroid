## 审查摘要

本项目是 Android 注音输入法 (IME)，基于 libchewing 0.12.x (Rust 重写版) 实现。
之前由 opencode/codex 执行到 wave4，遇到编译障碍。现已完成全面审查和修复。

## 发现的问题与修复

### CRITICAL (严重)

1. **Gradle/AGP 版本冲突**
   - 原: AGP 7.4.2 + Gradle 8.5 = 不兼容
   - 修复: AGP 8.2.0 + Gradle 8.7 + Java 11
   - 文件: `build.gradle.kts`, `app/build.gradle.kts`, `gradle-wrapper.properties`

2. **libchewing C API 不匹配**
   - 原: chewing_jni.cpp 使用旧 C API 命名 (gchar, gint, 旧函数名)
   - 修复: 完全重写以匹配 libchewing 0.12.x CAPI
   - 文件: `app/src/main/cpp/chewing_jni.cpp`, `AndroidChewingEngine.kt`

### MODERATE (中等)

3. **KeyboardView.kt 语法错误**
   - 原: 文件末尾有残留代码片段
   - 修复: 清理文件，恢复完整实现

4. **CandidateView.kt 功能缺失**
   - 原: 缺少翻页回调接口
   - 修复: 添加 `onPrevPage` 和 `onNextPage` 回调

5. **ChewingEngine.kt 接口不完整**
   - 原: 缺少 `toggleChiEng()`, `nextPage()`, `prevPage()`
   - 修复: 补充完整接口定义

### LOW (低)

6. **KeyMapping.kt 映射不完整**
   - 当前: 只映射了部分键
   - 建议: 后续 wave 扩展完整注音映射

## 架构验证

### 分层结构 ✅
```
UI Layer (KeyboardView, CandidateView, SymbolPicker)
    ↓
IMS Layer (ChewingInputMethodService)
    ↓
Core Layer (ChewingEngine interface, IMEConfig)
    ↓
Android Layer (AndroidChewingEngine - JNI)
    ↓
Native Layer (chewing_jni.cpp → libchewing)
```

### 依赖边界 ✅
- UI 层不直接调用 JNI
- JNI 调用集中在 AndroidChewingEngine
- Core 层保持平台无关

## 编译前置条件

1. **Android SDK** (包含 API 34)
2. **Android NDK r26b+**
3. **JDK 11+**
4. **Rust toolchain** (用于构建 libchewing)

## 构建命令

```bash
# 1. 构建 libchewing native library
cd app/src/main/cpp/libchewing-src/capi
cargo build --release --target-dir ../../build/cargo

# 2. 复制 .so 到 jniLibs
mkdir -p app/src/main/jniLibs/arm64-v8a
cp build/cargo/release/libchewing.so app/src/main/jniLibs/arm64-v8a/

# 3. 构建 APK
cd ../..
./gradlew :app:assembleDebug
```
