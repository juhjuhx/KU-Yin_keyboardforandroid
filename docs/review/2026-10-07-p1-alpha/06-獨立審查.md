## 已修正 findings

1. 01 深讀未限定 API 的 IME visibility 描述過廣。API 24–29 只用 isAcceptingText，代表 served view 接受 full text edits，不能證明 window visibility；API ≥30 才有 WindowInsets visibility assertion。已在 01／03／04 加限定。[官方語義](https://developer.android.com/reference/android/view/inputmethod/InputMethodManager#isAcceptingText())。
2. ContinuousSentenceTest 雖輸入兩音節，但 assertions 只確證非空 preedit、至少一個 CJK、非空 candidates／selected-preedit／final commit；不能嚴格證明兩音節完整 coexist、正確轉換或只 commit 一次。01／04 已校正；B03 保持完整待驗契約，不更改現有 test／產品源碼。
