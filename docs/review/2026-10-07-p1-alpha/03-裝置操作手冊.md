# P1 Alpha 實機操作手冊

本手冊使用 exact frozen APK，不執行既有 runtime_smoke.sh 的自動重建／設定選擇流程。以下命令尚未在裝置上執行。既有 host 不支援完整 editor matrix；成功跑完 5 測只能裁定「既有 smoke PASS」。

## 2. 裝置準備與辨識

使用測試手機及固定非敏感測試文字。開啟 USB debugging，連接 Mac，手機確認此電腦的 RSA 授權；以下命令以明示 serial 綁定同一台裝置，不自行挑第一台。

```bash
KUYIN_ADB=/opt/homebrew/share/android-commandlinetools/platform-tools/adb
"$KUYIN_ADB" devices -l
KUYIN_SERIAL='填入已授權實機的serial'
"$KUYIN_ADB" -s "$KUYIN_SERIAL" get-state
"$KUYIN_ADB" -s "$KUYIN_SERIAL" shell getprop ro.product.model
"$KUYIN_ADB" -s "$KUYIN_SERIAL" shell getprop ro.build.version.sdk
"$KUYIN_ADB" -s "$KUYIN_SERIAL" shell getprop ro.product.cpu.abi
"$KUYIN_ADB" -s "$KUYIN_SERIAL" shell getprop ro.kernel.qemu
"$KUYIN_ADB" -s "$KUYIN_SERIAL" shell am get-current-user
```

必須是 `device`；unauthorized／offline 停止。記錄 PHYSICAL／EMULATOR，不把 emulator 當作 physical-device acceptance。以下 secure-setting commands 適用一般測試手機主使用者（current user=0）；若為其他 user/profile，先核對該 API 的 `ime help`／settings user 語義，不混用 profile 設定。

## 3. 保留原狀態與安裝

先記錄原 default IME、完整 enabled list 及 KU-Yin 是否原已啟用；在設定變更前把以下輸出存成該裝置的測試 session evidence，還原時以此為準。

```bash
"$KUYIN_ADB" -s "$KUYIN_SERIAL" shell settings get secure default_input_method
"$KUYIN_ADB" -s "$KUYIN_SERIAL" shell ime list -s
"$KUYIN_ADB" -s "$KUYIN_SERIAL" shell pm path io.github.juhjuhx.kuyin
"$KUYIN_ADB" -s "$KUYIN_SERIAL" install -r -t build/p1-alpha-acceptance/app-debug.apk
"$KUYIN_ADB" -s "$KUYIN_SERIAL" install -r -t build/p1-alpha-acceptance/app-debug-androidTest.apk
"$KUYIN_ADB" -s "$KUYIN_SERIAL" shell pm list instrumentation
"$KUYIN_ADB" -s "$KUYIN_SERIAL" shell ime list -s -a
```

既有安裝若 signature 不同而 UPDATE_INCOMPATIBLE，停止；不自動 uninstall／pm clear，以免移除設定與 user dictionary。使用相容的測試裝置或另行處理安裝衝突。一般 install 成功只是安裝證據，不能寫 runtime PASS。

## 4. 執行既有 5 測

確認 `ime list` 的 canonical component 確實為下列值才 enable／select。此步會暫時改變測試裝置的鍵盤選擇；執行後依第 5 節還原。

```bash
KUYIN_IME='io.github.juhjuhx.kuyin/com.example.ime.KuYinInputMethodService'
"$KUYIN_ADB" -s "$KUYIN_SERIAL" shell ime enable "$KUYIN_IME"
"$KUYIN_ADB" -s "$KUYIN_SERIAL" shell ime set "$KUYIN_IME"
"$KUYIN_ADB" -s "$KUYIN_SERIAL" shell settings get secure default_input_method
"$KUYIN_ADB" -s "$KUYIN_SERIAL" shell am instrument -w   io.github.juhjuhx.kuyin.test/androidx.test.runner.AndroidJUnitRunner
```

結果須出現完整測試結束及 `OK (5 tests)`；不能只以 adb process exit 0 判 PASS。保存 raw result 與退出碼，逐列對應 4 類／5 方法；如有 failure、crash、timeout、少測或 missing instrumentation，裁定 FAIL／INCONCLUSIVE，再定位。沒有重跑直到綠的策略。

API 24–29 的 recreate 測試只以 isAcceptingText 判 binding，不證明 IME window visible；若要驗證可見性／可輸入，另收受控畫面與實際固定字串輸入證據。API ≥30 才有 WindowInsets visibility assertion。

既有 tests 自動關閉直接 native engine，ActivityScenario 也會 close；仍不證明 production onDestroy 每個錯誤分支的 native ownership。

## 5. 還原 IME 選擇

以第 3 節記錄的原 IME ID 還原，再核對 default 和 enabled list。只有 KU-Yin 原本沒啟用時才 disable；原本就是 KU-Yin 或原本已啟用則保留其原啟用狀態。

```bash
KUYIN_ORIGINAL_IME='填入第3節保存的原defaultIME'
"$KUYIN_ADB" -s "$KUYIN_SERIAL" shell ime set "$KUYIN_ORIGINAL_IME"
"$KUYIN_ADB" -s "$KUYIN_SERIAL" shell settings get secure default_input_method
```

原本沒有 KU-Yin enabled 時，還原 default 後另外執行：

```bash
"$KUYIN_ADB" -s "$KUYIN_SERIAL" shell ime disable "$KUYIN_IME"
"$KUYIN_ADB" -s "$KUYIN_SERIAL" shell ime list -s
```

原 default 不存在／無效或還原失敗時，不宣稱已還原；記錄並在裝置設定中確認。安裝的測試 APK 保留，不自行移除使用者原本安裝的 app。

## 6. 完整 P1 matrix 接續

按 `02-驗收矩陣.md` 收集 label／preedit／InputConnection action ID/count／newline delta／mode／learning 邊界。既有 host 的 multiline DONE 不代表 single-line DONE，也不能驗證 custom actionId=73；必須先補受控 debug-only editor fixture，或取得能直接證明相同 metadata 的獨立 host。

`ImeHostActivity` 為 non-exported，不使用 adb shell am start 硬開。軟鍵盤 Enter 接線不以 `adb input keyevent KEYCODE_ENTER` 替代。旋轉要真實發生，既有 ActivityScenario.recreate 只另列重建測試。
