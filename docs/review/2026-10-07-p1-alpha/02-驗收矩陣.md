## 判讀邊界

- D03～D08／D11 必須在 InputConnection／editor action boundary 記 action ID 與增量次數；NEXT／PREVIOUS 不可只憑畫面是否換焦點判對錯。
- D13／D14 必須先證明 preedit 非空，再按當前畫面的 Enter；不得用 adb KEYCODE_ENTER 當作軟鍵盤 callback 接線證據。
- C native learning 不能只由鍵盤變英文推定 disabled，也不能單憑 userdict.dat hash 不變推定未學習；需受控 native policy observer 或另一份直接證據。
- A03 的既有 CASE-6 rotation gate 是 crash／continue／重複副作用；未核定的組字旋轉保存政策只記 observation，不能新造契約。
- 機型、API、ABI、app APK SHA、test APK SHA、source SHA、當次 editor config 與 case ID 必須一併記錄。
- 異常出現先保存固定測試內容的最小證據，再定位 prerequisite；不開始 M4、不中途切 APK 版本。
