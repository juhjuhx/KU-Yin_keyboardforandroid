## 中文

- 點可見注音 **ㄨ、ㄛ**，先不要點聲調；候選列應可找到「我」。點「我」後，App 的實際文字應是「我」。不要用口述 UO 推測 ASCII；標準大千內部是 j/i。
- 清空這段合成文字，連點 **ㄨㄛ／ㄒㄧㄢ／ㄗㄞ**，不中途選字、不必補聲調。候選應可選「我現在」，點後實際文字應為「我現在」。途中漢字轉換可能隨上下文改變，尚未完成的注音不得無故消失。
- 再測有聲調 **ㄨㄛˇ／ㄒㄧㄢˋ／ㄗㄞˋ**；最後選「我現在」。
- 測「我」先選入 editor，再繼續打「現在」，實際文字最後應為「我現在」。
- 在未選字的 composition 用退格；Space／Enter 應完成組字一次，不同時送出 editor action 或多一個 newline。切到另一個 App 後輸入新的合成句，不能重送前一欄文字。

## 英文

切英文模式，打 `hel`／`hell`，應出現包含 `hello` 的離線候選；點選後實際 editor 為 `hello`。Space 只加入一個分隔符；退格、Shift／Caps Lock 各自確認。Password 欄位及 editor 要求抑制／自行提供 completion 時，不顯示英文字典建議。
