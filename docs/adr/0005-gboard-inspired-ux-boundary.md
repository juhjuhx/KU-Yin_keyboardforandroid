# ADR 0005 — Gboard-inspired UX boundary

- Status: accepted
- Context: M4 approved visual redesign risks pixel-copying proprietary assets.
- Decision: borrow geometry/interaction/density patterns only (candidate strip,
  key pitch, touch model, symbol organization); all assets original; no Google
  source/assets/logo.
- Consequences: M4 slices judged on behavior parity, never visual identity match.
- Alternatives rejected: pixel-clone (legal + maintenance risk).
- Evidence: M4 baseline audit `docs/review/M4-BASELINE-AUDIT.md`.
