核心功能

⌨️

自繪 Canvas 鍵盤

低延遲 Kotlin View/Canvas 渲染，單容器 onDraw 迴圈，硬體加速支援

🧠

libchewing 解碼

Linux 同款引擎，大千/Hsu/Eten26 三佈局，字頻排序 + 使用者詞庫

🔄

OpenCC 簡繁切換

一鍵 s2tw/tw2s 台灣優先，fallback s2t/t2s，零外部依賴

🔒

零網路權限

無 INTERNET 權限，無上報，純本地處理，隱私第一

🎨

Material You 3

動態取色、OLED 純黑、自訂背景，深色/淺色自動適應

📱

超 Gboard 尺寸

60dp 直立 / 48dp 橫排鍵高，比 Gboard 大 20%+，手控更精準
