## 三、维修经验总结

### 3.1 BOM 编码问题（关键发现）

**问题**: Windows 版 opencode/codex 写入 Kotlin 文件时添加 UTF-8 BOM (`ef bb bf`)，导致 Kotlin 编译器报错：
```
e: file:///.../AndroidChewingEngine.kt:1:1 Expecting a top level declaration
```

**修复方法**:
```powershell
# 检测 BOM
head -c 3 file.kt | xxd

# 移除 BOM
$content = Get-Content file.kt -Raw
$content.Substring(1) | Set-Content file.kt -NoNewline
```

**当前状态**:
- `ChewingInputMethodService.kt` ✅ 无 BOM
- `KeyboardView.kt` ✅ 无 BOM  
- `SymbolPicker.kt` ✅ 无 BOM
- `KeyMapping.kt` ✅ 无 BOM
- `AndroidChewingEngine.kt` ❌ 有 BOM（需修复）
- `CandidateView.kt` ❌ 有 BOM（需修复）

### 3.2 JNI 函数命名转换

**规则**: `_` → `1`（下划线转义）

| C++ 函数名 | Kotlin 声明 |
|------------|-------------|
| `chewing_new()` | `chewing_1new(): Long` |
| `chewing_handle_Default()` | `chewing_1handle_1default()` |
| `chewing_cand_TotalChoice()` | `chewing_1cand_1Total_1Choice()` |
| `chewing_buffer_String_static()` | `chewing_1buffer_1string_1static()` |

### 3.3 InputMethodService 生命周期

**关键方法签名**:
```kotlin
override fun onCreateInputView(): View
override fun onStartInput(attribute: EditorInfo, restarting: Boolean)
override fun onStartInputView(attribute: EditorInfo, restarting: Boolean)  // 注意有两个参数
override fun onFinishInput()
override fun onFinishInputView(finishedTyping: Boolean)
```

**常见错误**:
- `onStartInputView` 只有一个参数 → 编译错误
- 返回 null 或异常 → 键盘不显示

### 3.4 键盘布局设计

**Dachen 布局映射**（libchewing 标准）:
```
Row 1: ㄅ KEY_1=10  ㄉ KEY_2=11  ˋ KEY_3=12  ˇ KEY_4=13  ㄓ KEY_5=14
Row 2: ㄆ KEY_Q=24  ㄊ KEY_W=25  ㄍ KEY_E=26  ㄐ KEY_R=27  ㄔ KEY_T=28
Row 3: ㄇ KEY_A=38  ㄋ KEY_S=39  ㄌ KEY_D=40  ㄏ KEY_F=41  ㄕ KEY_G=42
Row 4: ㄈ KEY_Z=52  ㄌ KEY_X=53  ㄒ KEY_C=54  ㄖ KEY_B=56  ㄙ KEY_N=57
```

**Android KeyEvent 与 xkbcommon 键码完全不同**，需要转换层。

### 3.5 View 堆叠方案

使用 `FrameLayout` 堆叠键盘和候选词视图：
```kotlin
val container = FrameLayout(this).apply {
    addView(keyboardView)
    addView(candidateView)
    addView(symbolPicker)
}
return container
```
