### 2.5 KeyMapping.kt 键位映射核查

**标准布局** (来自 `standard.rs`):
```
KEY_D (40) → ㄎ
KEY_F (41) → ㄑ
KEY_J (44) → ㄨ
KEY_X (53) → ㄌ
KEY_C (54) → ㄏ
KEY_V (55) → ㄒ
```

**当前 KeyMapping.kt**:
```
KEY_X (53) → ㄌ ✅
KEY_C (54) → ㄋ ❌ (应为 ㄏ)
KEY_V (55) → ㄋ ❌ (应为 ㄒ)
KEY_B (56) → ㄌ ❌ (应为 ㄖ)
```

**结论**: KeyMapping.kt 存在**键位错误**，与 libchewing 标准布局不一致。
